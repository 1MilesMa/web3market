规模变大之后怎么办

tokenId 上千之后逐个查询就不现实了。届时的标准做法是监听 Listed / PriceUpdated / Canceled / Sold 事件，在链下（数据库或前端内存）维护一份索引， 再用 getListing 做交叉校验。项目里的 scripts/market-board.js 就是这个思路的完整实现，可以直接 npx hardhat run 跑。
