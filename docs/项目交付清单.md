## 三、一键复现步骤

在项目目录下依次执行（PowerShell）：

```powershell
# 0. 如遇脚本执行策略拦截
Set-ExecutionPolicy -Scope Process Bypass -Force
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

# 1. 安装依赖
npm install

# 2. 配置环境变量（复制 .env.example 为 .env，填测试网私钥）
#    SEPOLIA_RPC_URL / PRIVATE_KEY / PRIVATE_KEY_2 / PRIVATE_KEY_3

# 3. 编译
npx hardhat compile

# 4. 跑测试 → 预期 296 passing
npx hardhat test

# 5. 本地零成本演练出价全流程
npx hardhat run scripts/practice-offer.js

# 5b. 本地零成本演练 EIP-712 签名挂单（12 步）
npx hardhat run scripts/practice-eip712.js

# 6. 部署（可选，会消耗测试币）
npx hardhat run scripts/deploy-mynft.js --network sepolia
npx hardhat run scripts/deploy-market.js --network sepolia

# 6b. 部署多签治理合约（幂等：已部署则复用，不会作废旧地址）
npx hardhat run scripts/deploy-multisig-sepolia.js --network sepolia

# 6c. 把市场 owner 移交给多签（两步走，不可逆，确认后再跑）
npx hardhat run scripts/transfer-market-to-multisig.js --network sepolia

# 6d. 多签治理本地演练（零成本，不需要连网）
npx hardhat run scripts/practice-multisig.js

# 6e. 时间锁本地演练（零成本，31 项断言）
npx hardhat run scripts/practice-timelock.js

# 6f. 部署时间锁（公示延迟可用环境变量覆盖，默认 3600 秒）
$env:TIMELOCK_DELAY_SECONDS = 300
npx hardhat run scripts/deploy-timelock-sepolia.js --network sepolia

# 6g. 把市场 owner 从多签移交时间锁（可重入，跑两次：排队一次 + 公示到期再跑一次）
npx hardhat run scripts/transfer-market-to-timelock.js --network sepolia

# 6h. 时间锁治理实战（脚本内自动等待公示：改费率 → 生效 → 还原，零残留）
npx hardhat run scripts/verify-timelock-governance.js --network sepolia

# 7. 链上实跑出价流程（需先给买家账户转测试币）
npx hardhat run scripts/practice-offer.js --network sepolia

# 7b. 链上实跑 EIP-712 签名挂单
#     注意：市场合约必须含 fulfillListing / listingNonces，旧地址会直接报错退出
npx hardhat run scripts/practice-eip712.js --network sepolia
```

> `npx` 若在 PowerShell 被拦截，改用 `npx.cmd`。
