| 3.5 | 资金退出是否 Pull Payment | 推送式付款遇拒收方会整笔成交失败、把资金卡死 | 读 `_settleSale` / `_splitProceeds` | **已达标** — 三方分账中卖家是**实时到账**，但对可能拒收的接收方（版税收款方、退款对象）降级为 `pendingRoyalties` / `pendingWithdrawals`，由收款方自取；演示脚本阶段 3 验证"创作者余额在成交瞬间未变，调用 `withdrawRoyalties()` 后才到账" |
| 3.6 | 出价的失效与撤回规则 | 出价资金长期锁在合约里会成为沉淀资产 | 读 `makeOffer` / `acceptOffer` / `withdrawOffer` | **已达标** — NFT 易主后旧出价失效（防止新持有者被旧报价强买）；出价人可随时 `withdrawOffer`，持有者可 `rejectOffer`；演示脚本阶段 4 验证"出价 ETH 托管进合约 → 成交后出价清零" |
